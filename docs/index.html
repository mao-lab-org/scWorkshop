Modelling Continuous Cell States Using scRNA-seq Data

BiocAsia 2026 workshop

Single-cell RNA-seq analyses usually sort cells into clusters and give each cluster one label. Many questions, though, are about cells in transition: cells that are differentiating, maturing or responding to a stimulus. This 3-hour workshop treats such cell states as continuous, using snRNA-seq of the maturing human heart.

Data

snRNA-seq of the human heart at foetal, young and adult stages:

Sim CB, et al. Sex-specific control of human heart maturation by the progesterone receptor. Circulation 2021;143(16):1614–1628. doi:10.1161/CIRCULATIONAHA.120.051921

The Φ-Space reference is a subset of the Gao et al. (2026, Genome Biology) snRNA-seq atlas of the human left ventricle.

Running the materials yourself

The pages on this site were rendered from the workshop’s saved results. To run the code, you need R 4.6 (Bioconductor 3.23), the workshop repository and its data. From the repository root:

source("setup/install_packages.R")   # R packages
source("setup/download_data.R")      # data + saved results from Zenodo (~2.7 GB)
source("setup/check_setup.R")        # verify

Then open the files in vignettes/ in RStudio and run the chunks in order.
